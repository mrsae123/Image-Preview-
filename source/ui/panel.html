How Image Preview works
Preview & pin images

Paste an image link or a webpage link, then tap Preview. Pin on chat keeps it floating over the chat so you can look at it while you type. Drag to move, pinch or use +/- to resize. The pin's toolbar also has reset, rotate, flip, fullscreen and remove; tap ︿ to fold the toolbar away.

Save & manage images

Save preview keeps a copy for this chat. Tap any saved image for Fullscreen, Pin, Save to device, Copy link, Rename, Info and Delete. Rename only changes the label; the image itself is never touched.

Quick Lookup ⚓

The ⚓ hangs on a rope and sways by itself. Pull it down to open Translate, Meaning and Web Search. To close, tap the ⚓ or pull it down again. A tap on the closed anchor only gives the rope a tug.

Game Corner

Tap 🎮 for a Jump Game, Snake and Memory Bomb, or add your own game. Drag the top bar to move the window and the corner to resize it. The ⚙ button inside a game holds your player name and that game's own settings and resets.

Your privacy

Saved images and pins belong only to this chat. Built-in games are fully offline. Games you add yourself run in an isolated box and cannot read your chats or Tavo data. Privacy Mode blocks every lookup request.
